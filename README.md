# Славянские сказки

Родственный сайт к [«Славянским богам»](https://shleenkov88.github.io/slavic-gods/): народные русские сказки из сборника А. Н. Афанасьева для чтения, персонажи, сюжеты и осторожные связи с богами.

Адрес по умолчанию: https://shleenkov88.github.io/slavic-tales/

## Устройство

Статичный одностраничный сайт без сборки и без внешних скриптов и шрифтов.

- `index.html` — вся разметка; полные тексты пяти сказок лежат в блоке `#texts` (без JavaScript они просто читаются подряд);
- `styles.css` — тёмный фон, золотые акценты, шапка в одну строку, режим чтения;
- `app.js` — меню, режим чтения (карточка → крупный шрифт, A−/A+, варианты сказки, переходы между сказками, адрес вида `#tale-morozko`);
- `fonts/` — Ruslan Display и Philosopher (те же файлы, что на «Славянских богах», лицензия SIL OFL);
- `favicon.svg`.

Ссылки на разделы и сказки относительные. Абсолютные адреса только у ссылок на сайт «Славянские боги» и в `og:url`.

## Тексты

Сказки взяты с Викитеки, из сборника «Народные русские сказки» А. Н. Афанасьева (Викитека даёт текст по изданию «Наука», 1984—1985, серия «Литературные памятники»; на странице сборника отмечено, что произведение не охраняется авторским правом).

| Сказка на сайте | В сборнике | Страница источника |
|---|---|---|
| Баба-Яга | «Баба-яга», № 102—103 | https://ru.wikisource.org/wiki/Народные_русские_сказки_(Афанасьев)/Баба-яга |
| Василиса Прекрасная | «Василиса Прекрасная», № 104 | https://ru.wikisource.org/wiki/Народные_русские_сказки_(Афанасьев)/Василиса_Прекрасная |
| Морозко | «Морозко», № 95—96 | https://ru.wikisource.org/wiki/Народные_русские_сказки_(Афанасьев)/Морозко |
| Царевна-лягушка | «Царевна-лягушка», № 267—269 | https://ru.wikisource.org/wiki/Народные_русские_сказки_(Афанасьев)/Царевна-лягушка |
| Кощей Бессмертный | «Кощей Бессмертный», № 156—158 | https://ru.wikisource.org/wiki/Народные_русские_сказки_(Афанасьев)/Кощей_Бессмертный |

Что сделано с текстом: взяты все варианты каждой сказки; убраны номера сносок и сами примечания (в том числе глоссы издателей), буквица склеена со словом. Слова не менялись, орфография такая, как даёт источник (современная).

## Что ещё не сделано

- Иллюстрации — следующий шаг (сейчас только типографика и CSS-орнамент).
- Озвучки нет.
- Сноски и словарик устаревших слов (коник, челпан и т. п.) не включены; их можно написать самим.
- Раздел «Что говорят учёные» есть только у тех персонажей, где мнение удалось проверить по открытому источнику; про остальных строки нет.
