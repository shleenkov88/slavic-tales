# Славянские сказки

Родственный сайт к [«Славянским богам»](https://shleenkov88.github.io/slavic-gods/): народные русские сказки из сборника А. Н. Афанасьева для чтения, персонажи, сюжеты и осторожные связи с богами.

Адрес по умолчанию: https://shleenkov88.github.io/slavic-tales/

## Устройство

Статичный одностраничный сайт без сборки и без внешних скриптов и шрифтов.

- `index.html` — вся разметка; полные тексты пяти сказок лежат в блоке `#texts` (без JavaScript они просто читаются подряд);
- `styles.css` — тёмный фон, золотые акценты, шапка в одну строку, режим чтения;
- `app.js` — меню, режим чтения (карточка → крупный шрифт, A−/A+, варианты сказки, полоска прогресса, переходы между сказками, адрес вида `#tale-morozko/95`);
- `fonts/` — Ruslan Display и Philosopher (те же файлы, что на «Славянских богах», лицензия SIL OFL);
- `favicon.svg`.

Ссылки на разделы и сказки относительные. Абсолютные адреса только у ссылок на сайт «Славянские боги» и в `og:url`.

## Музыка, «Наверх», «Продолжить чтение»

- **Музыка** — `audio/music/*.mp3` (3 трека Kevin MacLeod, incompetech.com, CC BY 4.0; названия, ссылки и условия — в разделе «Источники текстов» и в подвале страницы). Выключена по умолчанию, включается кнопкой 🎵 (запоминается в `localStorage`, ключ `tales-music`; если была включена, стартует после первого клика или нажатия Enter/Пробел, не сама). Громкость 0,25 через Web Audio (на iOS `audio.volume` не работает), плавное появление и затухание, треки идут по кругу. Пока играет голос сказки (`#r-audio`), музыка затухает и ставится на паузу, потом возвращается. Файлы сжаты в mp3 96 кбит/с, громкость выровнена, добавлены короткие плавные начало и конец.
- **Сворачивание.** Когда вкладка скрыта или окно потеряло фокус (`visibilitychange`, `pagehide`, `blur`), музыка за ~0,8 с затухает и ставится на паузу; при возврате (`visible`/`focus`) плавно возвращается до 0,25 с того же места — только если её включил пользователь. Пауза «вкладка скрыта» и пауза «играет голос» учитываются независимо (`away` и `voiceOn`): музыка не включится поверх голоса.
- **Пергамент в режиме чтения.** По умолчанию страница чтения — светлый тёплый пергамент (CSS-градиенты и два лёгких SVG `feTurbulence` внутри `styles.css`, без картинок): виньетка по краям, «чернильный» тёмно-коричневый текст (контраст ≥ 7:1), буквица и заголовок тёмно-красные, шапка, плавающие кнопки и плеер озвучки перекрашены. Кнопка ☾/☀ в шапке чтения переключает «Свет/Ночь» (`localStorage`, ключ `tales-rt`, `html[data-rt]`). Главная и остальные разделы остаются тёмными, печать не затронута.
- **↑ Наверх** — плавающая кнопка справа внизу, появляется после прокрутки больше одного экрана; в режиме чтения прокручивает текст сказки. Учитывает `prefers-reduced-motion`.
- **Продолжить чтение** — позиция чтения (сказка, вариант, номер абзаца, процент) хранится в `localStorage` (`tales-progress`, `tales-last`). На главной под кнопками показывается плашка «Продолжить чтение: название · N%»; скрыта, если ничего не читали или дочитали до конца; «Начать заново» стирает место. Ошибки `localStorage` перехватываются.

## Поиск, прогресс, навигация

- **Поиск и фильтры** (над списком сказок, всё в `app.js`, без перезагрузки): строка поиска по названию, героям и словам из первых абзацев (регистр и ё/е не важны, окончания терпимы); метки героев (Баба-Яга, Кощей, Морозко, Волк, Медведь, Жар-птица, Василиса, Иван-царевич, Ведьма, Мачеха, Щука — метка показывается, только если герой есть в текстах сайта, список считается по тексту при загрузке); длина («до 5 мин», «на вечер» — больше 10 мин); «есть озвучка»; «Случайная сказка». Пустой результат — подсказка и три похожие сказки.
- **Прогресс** — `localStorage`, ключ `tales-p2` (`{v:2, i:{"slug/№": {p, i, t, d, ts}}}`: процент, абзац, секунда озвучки, «прочитана», время). Старые ключи `tales-progress`/`tales-last` при первом запуске переносятся (сами остаются). Прогресс — самое дальнее место, до которого дошли прокруткой; прыжок к началу его не сбрасывает, а кнопки «Дальше»/«К концу» его не засчитывают. Если `localStorage` недоступен, всё работает до закрытия страницы. В режиме чтения: полоса прогресса сверху, подпись «Осталось ~N мин» (150 слов/мин; после старта озвучки — ещё «голос: ~M мин» по оставшейся длительности), кнопки «Отметить прочитанной» и «Сбросить». В списке у каждой записи отметка «не начата / в процессе N% / прочитана». На главной: «Продолжить чтение» (самая свежая) и «Недочитанные» (до 3 других).
- **Навигация:** меню — Сказки, Персонажи, Разбор, Связь с богами (+ ссылка на сайт про богов), текущий раздел подсвечен; «← К сказкам» возвращает на то же место списка с теми же фильтрами; внизу чтения «Предыдущая / Следующая»; «Ещё сказки, где есть: …» — только если герой упомянут не меньше 3 раз в обеих сказках. Раздел «Сюжеты» остаётся на странице, ссылка на него — в описании «Персонажей».
